# Chat

Status: 💡 idea (not yet implemented)

## Overview

Persistent text conversation within a Nest. One of the two product
pillars — see [../product/scope.md](../product/scope.md).

## Core

- Real-time messaging within a Nest
- Message reactions
- Message history, persisted

## Sub-features

| Sub-feature | Status | Notes |
|---|---|---|
| Roast Assistant | 💡 idea, details deferred | AI-assisted rewrite of a message toward a chosen tone (playful/hurtful/funny). Exact UX, model choice, and scope not yet defined — intentionally deferred, see [../product/glossary.md](../product/glossary.md). |
| Confession Booth | 💡 idea | Anonymous (peer-facing only, not moderator-facing) posting mode within a Nest. |
| W/L Scoreboard | 💡 idea | Casual per-user win/loss tally within a Nest, self- or peer-declared. |

## Constraints

- Any sub-feature involving anonymity must remain traceable to
  moderators/admins even when anonymous to peers — see
  [../product/principles.md](../product/principles.md).
