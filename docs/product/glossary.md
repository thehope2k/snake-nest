# Glossary

**Nest**
The one and only container in the app. A group of people — a friend
group, a workplace side-channel, whatever — sharing one Chat and one
Meet. There's no bigger structure above it, and a person can be in as
many Nests as they like.

**Chat**
The persistent text conversation inside a Nest.

**Meet**
The drop-in voice/video call inside a Nest.

**Doghouse**
During a call, muting someone out loud, on purpose, for everyone to see
— a way of saying "we're talking about you" as a bit instead of doing it
secretly. See [../architecture.md](../architecture.md) for how it's
meant to work and the limits it has to ship with.

**Roast Assistant** *(just an idea so far)*
A rough idea for Chat: something that helps rewrite a message to be more
playful (or more savage) before you send it. Not designed yet.

**Confession Booth** *(just an idea so far)*
A way to post anonymously inside a Nest — anonymous to the other people
in it, not to moderators.

**Roast Leaderboard / W-L Scoreboard** *(just an idea so far)*
A casual running tally per Nest — who's been Doghoused the most, who's
"winning," that sort of thing.

**Soundboard** *(just an idea so far)*
Short sound effects anyone in a call can play for the whole room.
